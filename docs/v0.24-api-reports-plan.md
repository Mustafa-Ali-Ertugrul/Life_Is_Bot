## Endpoint'ler (hepsi `get_current_user` korumalı)

| Method | Path | Query parametreleri | Yanıt |
|---|---|---|---|
| GET | `/api/reports/daily` | `date: date \| None = None` (kullanıcı TZ'de bugün default) | `ReportDailySchema` |
| GET | `/api/reports/weekly` | `week_start: date \| None = None` (bu hafta default) | `ReportWeeklySchema` |
| GET | `/api/reports/monthly` | `year: int \| None = None`, `month: int \| None = None` (kullanıcı TZ'de şu anki ay default) | `ReportMonthlySchema` |

- `date` / `week_start`: FastAPI `date` tipi → `YYYY-MM-DD`, geçersiz format otomatik **422**.
- `month`: `Field(ge=1, le=12)` → geçersiz **422**; `year`: `Field(ge=1)`.
- Default yıl/ay hesaplaması: `settings_service.get_settings(session, user_id)` + `now_in(user.timezone)` (bot'taki `_current_year_month` ile aynı desen).
- Boş rapor (total=0): **200** döner, sayaçlar 0, listeler boş (404 DEĞİL).

## Schema'lar (`app/api/schemas/report.py`)

```python
class ReportDailySchema(BaseModel):
    date: date
    total: int
    completed: int
    missed: int
    unanswered: int
    completed_items: list[str]
    missed_items: list[str]
    step_steps: int | None
    step_goal: int | None

class ReportWeeklySchema(BaseModel):
    week_start: date
    week_end: date
    total: int
    completed: int
    missed: int
    unanswered: int
    compliance_rate: int
    best_day: int | None   # ISO weekday 1-7
    weakest_day: int | None

class ReportBotStatsSchema(BaseModel):
    bot_key: str
    total: int
    completed: int
    missed: int
    snoozed: int
    pending: int
    completion_rate: float   # 0-100, 1 ondalık

class ReportMonthlySchema(BaseModel):
    user_id: int
    year: int
    month: int
    bot_stats: list[ReportBotStatsSchema]
    total: int
    total_completed: int
    total_missed: int
    total_snoozed: int
    total_pending: int
    completion_rate: float

    @classmethod
    def from_report(cls, report: MonthlyReport) -> ReportMonthlySchema: ...
```

- `DailyReport` / `WeeklyReport` (TypedDict) doğrudan FastAPI `response_model` doğrulamasından geçer; router'da `ReportDailySchema(**data)` / `ReportWeeklySchema(**data)` ile kurulur.
- `MonthlyReport` (dataclass) → `ReportMonthlySchema.from_report(...)` dönüşümü; `completion_rate` property'leri schema'da karşılığıyla birebir (bot bazında `round(completed*100/total, 1)`).

## Testler (`tests/test_api_reports.py`, ~13)

1. `test_reports_require_auth` — auth'suz → 401
2. `test_daily_default_empty` — boş DB, default → 200, tam şekil (total=0, `completed_items == []`, `step_steps is None`)
3. `test_daily_with_date` — belirli tarih → 200
4. `test_daily_invalid_date` — `date=2026-13-99` → 422
5. `test_daily_counts_events` — user1: 1×POSITIVE, 1×NEGATIVE, 1×NO_RESPONSE (bugün, kullanıcı TZ) → completed=1, missed=1, unanswered=1, completed_items içeriği
6. `test_weekly_default_empty` — → 200, week_start/end bu hafta
7. `test_weekly_with_week_start` — → 200
8. `test_weekly_counts_events` — hafta içi event'ler → compliance_rate doğru
9. `test_monthly_year_month` — belirli yıl/ay → 200, bot_stats=[]
10. `test_monthly_default_current` — year/month'suz → 200
11. `test_monthly_invalid_month` — month=13 → 422
12. `test_monthly_counts_events` — 2 bot_key'li event'ler → bot_stats 2 eleman, completion_rate
13. `test_reports_scoped_to_user` — user2 event'leri user1 raporunda görünmez

Not: event kurulumu `ReminderEvent` modelinin zorunlu alanlarıyla yapılır (denetimde doğrulanacak).
Denetim bulgusu (D1): test fixture'ında `scheduled_local_date`, kullanıcı TZ'sinde kurulmalı:
`now_in(user.timezone).date()` (config `settings.timezone`'a bağımlı kalmamak için; `User.timezone`
default "Europe/Istanbul", report_service `_user_timezone_name` `name or settings.timezone` kullanır).
`ReminderEvent` zorunlu alanları: `user_id`, `bot_key`, `scheduled_at` (tz-aware UTC), `scheduled_local_date`,
`dedupe_key` (user_id+dedupe_key UNIQUE — her event için benzersiz değer); `status`/`interpretation_json`
default'lu. `ReminderStatus` değerleri: POSITIVE="positive", NEGATIVE="negative", NO_RESPONSE="no_response".
